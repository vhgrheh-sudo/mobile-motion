# What this engine is

This folder's engine is an independent Python/OpenCV frame renderer that
approximates a subset of the source app's effect shaders. It is not the app's
native engine, does not read its project files, and does not execute its XMLs.

Portability verdict, ABI evidence, runtime stack, export-cap grep and the
reporting rule: `references/engine-portability.md`.

Keep this file short; do not record session-specific device state here.
